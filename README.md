# Fixing Back Pain For Good

A high-converting landing page for **Fixing Back Pain For Good**, a sub-brand of [Richard Aceves](https://www.richardaceves.com).

This is a static page (`index.html` + `css/` + `js/` + `images/`). It can be dropped into a Wix custom embed, Webflow, Netlify, or any static host.

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Primary conversion

The one action on the page is **Book Your Assessment**. The short form at `#apply` opens a prefilled email to `info@richardaceves.com`. Wire that form to Typeform, Calendly, or the existing Richard Aceves intake when those URLs are ready.
